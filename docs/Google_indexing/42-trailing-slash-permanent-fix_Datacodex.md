# 🗺️ [الحل الجذري لمشكلة الـ Trailing Slash]
> **الإصدار:** 1.4.3
> **التاريخ:** 2026-05-09
> **المنهجية:** Multi-Model Development

## 🎯 الهدف العام
إصلاح جذري ونهائي لمشكلة غياب الـ Trailing Slash في الروابط الداخلية (16 رابط مكسور) عبر أتمتة الإضافة من خلال دالة `url()` مساعدة وسكربت `post-build` لضمان صحة الفهرسة والموثوقية في Google.

## 📅 المراحل التنفيذية

### **المرحلة 1: جرد نهائي (Re-scan) 🔍**
> **النموذج:** `Gemini 3.1 Pro` 🟠
> **الهدف:** فحص شامل للكود قبل التنفيذ للتأكد من عدم وجود روابط إضافية فاتتنا.
> **يعتمد على:** المرحلة 0 ✅

| تنفيذ | مراجعة | المهمة |
| :---: | :---: | :--- |
| `[x]` | `[ ]` | إجراء بحث (grep_search) شامل في مجلدات src و components و pages و layouts للبحث عن الروابط الديناميكية والثابتة و hreflang غير المكتشفة التي تنقصها الـ / |
| `[x]` | `[ ]` | تحديث الخطة إذا تم العثور على أخطاء جديدة وإضافتها للقائمة. |

**🔄 برومبت بدء هذه المرحلة:**
```markdown
قم بإجراء مسح شامل (Re-scan) باستخدام أداة `grep_search` للكود المصدري في المشروع (خاصة `href=` و `alternateUrl`) للتأكد من عدم وجود روابط داخلية تفتقد الـ Trailing Slash غير الـ 16 المذكورة. قم بتقديم تقرير مختصر.
```

### **المرحلة 2: إنشاء دالة `url()` helper 🛠️**
> **النموذج:** `Gemini 3.1 Pro` 🟠
> **الهدف:** توحيد توليد الروابط في الكود لضمان إضافة السلاش في النهاية دائماً.
> **يعتمد على:** المرحلة 1 ✅

| تنفيذ | مراجعة | المهمة |
| :---: | :---: | :--- |
| `[x]` | `[ ]` | إنشاء ملف `src/utils/url.ts` |
| `[x]` | `[ ]` | كتابة دالة `url(path: string)` تضمن وجود الـ Trailing Slash وتستثني روابط الملفات الثابتة أو الروابط الخارجية |

**🔄 برومبت بدء هذه المرحلة:**
```markdown
قم بإنشاء دالة مساعدة `url()` في ملف `src/utils/url.ts` لتأمين الروابط الداخلية. الدالة يجب أن:
1. تقبل مسار النص.
2. تتحقق مما إذا كان ينتهي بسلاش `/` وإذا لم يكن، تضيفه.
3. تستثني الروابط الخارجية (http) وروابط الملفات (التي تحتوي على امتداد مثل .pdf, .xml).
```
